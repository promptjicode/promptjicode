# 02 · هالكود شغّال… بس بيكذب عليك

**▶ [جرّب العدادين](https://promptjicode.github.io/promptjicode/02-countdown-timer/)**: شغّلهم، واقفل شاشة موبايلك دقيقة، وارجع.

## البرومبت العادي

</div>

```
اعملي عداد تنازلي لـ 10 دقايق
```

<div dir="rtl">

النتيجة: كود بيشتغل، بس بيعدّ **المرات** مو **الوقت**:

</div>

```js
let seconds = 10 * 60;
setInterval(() => {
  seconds--;
  // ...
}, 1000);
```

<div dir="rtl">

لما تقفل الشاشة أو تروح على تاب تاني، المتصفح بيوقّف التايمرات أو بيبطّئها. فبيتأخر العداد بقد ما الشاشة ضلت مقفولة.

## البرومبت الصح

</div>

```
اعملي عداد تنازلي لـ 10 دقايق، ولازم يضل دقيق حتى لو المستخدم طلع من التاب أو قفل الشاشة.
```

<div dir="rtl">

النتيجة: بيحفظ وقت النهاية وبيحسب الباقي من الساعة الحقيقية بكل تحديث:

</div>

```js
const end = Date.now() + 10 * 60 * 1000;
function tick() {
  const left = Math.max(0, end - Date.now());
  // ...
  if (left > 0) requestAnimationFrame(tick);
}
tick();
```

<div dir="rtl">

## الفكرة

الكود اللي بيشتغل مش دايماً صح. **قلّه بالبرومبت شو الحالات الصعبة** اللي لازم ينجح فيها.

</div>
