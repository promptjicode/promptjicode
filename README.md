## كيف تجرّب

1. افتح مجلد الريل.
2. انسخ البرومبت من `prompt.md` وجرّبه بأداة الذكاء الاصطناعي اللي بتستخدمها.
3. قارن نتيجتك بالصفحة الحية من عمود **جرّب**.
