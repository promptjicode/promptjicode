🛟 أنقذتك من كارثة #03 · Git

عملت reset --hard… وراح شغلك؟

لا تخاف، Git ما بينسى شي. git reflog بيوريك كل مكان كان فيه الـ HEAD، حتى الـ commits اللي «مسحتها». انسخ الأوامر، أو جرّب بالمحاكي.

🧪 المحاكي

⚠️ reflog بيرجّع بس الشغل اللي كان معمولو commit. التعديلات اللي ما انحفظت بـ commit وراحت بـ --hard ما بترجع. والـ reflog محلي على جهازك، وبيضل حوالي 90 يوم.

1. git reflog: لستة بكل مكان كان فيه الـ HEAD. أول سطر HEAD@{0} هو هلّق، وHEAD@{1} هو المكان اللي قبلو.

2. git reset --hard HEAD@{1}: رجّع الـ branch لهديك النقطة، فبيرجعوا الـ commits.

إذا عملت كذا أمر بعد الغلط، ما بيكون دايماً {1}. دوّر باللستة على آخر commit بتعرفه، واستعمل الرقم تبعه أو الـ hash.
