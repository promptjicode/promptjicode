🛟 أنقذتك من كارثة #01 · Git

عملت commit على main بالغلط؟

الحل بـ 3 أوامر. انسخهم من هون، أو جرّبهم بالمحاكي تحت وشوف شو بيصير بالـ branches خطوة خطوة.

🧪 المحاكي

$ git log --oneline a91f2e (HEAD -> main) login page ← oops, on main

اضغط «شغّل» على الأمر الأول.

⚠️ هالطريقة إذا لسا ما عملت push، وما عندك تعديلات مش محفوظة (git status لازم يكون نضيف)، لأنو --hard بيمسح أي تعديل مش محفوظ. إذا عملت push، الحل بالريل الجاي.

1. git switch -c login: بيعمل branch جديد اسمه login من مكانك هلّق، فالـ commit صار فيه كمان.

2. git switch main: رجعنا على main.

3. git reset --hard HEAD~1: main رجع commit واحد لورا. الـ commit ما انمحى، لسا على login.
