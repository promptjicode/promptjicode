🛟 أنقذتك من كارثة #02 · Git

عملت push… وبعدين انتبهت إنو في غلط؟

الكود صار على السيرفر وعند الفريق، فما منمسح التاريخ. منعمل commit جديد بيلغي الغلط. انسخ الأوامر من هون، أو قارن الطريقتين بالمحاكي.

🧪 المحاكي: جهازك، والسيرفر، وجهاز سارة

⚠️ git revert HEAD بيلغي آخر commit. إذا الغلط بـ commit أقدم، جيب الـ hash تبعه من git log --oneline واكتب git revert <hash>.

ليش مش reset؟ الـ commit صار على السيرفر، وسارة سحبته وبنت فوقه. reset مع push --force بيغيّر التاريخ على السيرفر، فتاريخ سارة ما عاد يطابقه، ولما تعمل push ممكن يرجع الغلط أو يضيع شغل.

1. git revert HEAD: بيعمل commit جديد عكس الغلط. التاريخ ما بيتغير، بس بينضاف عليه.

2. git push: push عادي، بدون force. والفريق بياخد التصحيح بـ git pull متل أي commit.
