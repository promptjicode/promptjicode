حذفت Milk… ليش انتقل الـ ✓؟

هاد React حقيقي. كل سطر عنده state لحاله (done). القائمة الأولى بـ key={i}، والتانية بـ key={item.id}.

  1. علّم ✓ على Bread
  2. احذف Milk بزر ✕
  3. شوف وين صار الـ ✓

ليش؟ React بيعرف كل سطر من الـ key تبعه، مش من محتواه. مع key={i}، Bread كان key=1 والـ ✓ تبعه مربوط بـ key=1. لما حذفنا Milk صار Eggs هو key=1، فـ React خلّى الـ state وحطّ عليها Eggs.

الحل: key={item.id}، معرّف ثابت ما بيتغيّر مع الترتيب. وkey={Math.random()} أسوأ: كل مرة بتتغيّر القائمة (حذف، إضافة، أو أي render للأب) بيمسح كل الأسطر وبيعملها من جديد، فالـ ✓ بيختفي.
