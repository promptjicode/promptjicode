تلات طلبات… وحدة فشلت. شو بيصير؟

اختار لكل طلب إذا بينجح أو بيفشل، وشغّل نفس الطلبات مرة بـ Promise.all ومرة بـ Promise.allSettled. هاد كود حقيقي بيشتغل بالمتصفح.

// console

ليش error: posts؟ Promise.all يا كلهن ينجحوا… يا ولا شي. أول ما وحدة ترفض (posts بعد 100ms) بيرفض كلو فوراً، وما بيستنى الباقي. الطلبين التانيين بيكمّلوا، بس نتيجتهن بتضيع، ومنروح على catch.

والحل؟ إذا بدك النتايج الناجحة حتى لو وحدة فشلت، استعمل Promise.allSettled: بيستنى الكل، وبيعطيك لكل وحدة status: 'fulfilled' أو 'rejected'.

وهلّق إذا…؟ بالـ allSettled مع map(x => x.status) بيطبع ['fulfilled', 'rejected', 'fulfilled']. جرّبها بالزر التاني.
