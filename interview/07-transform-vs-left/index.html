نفس الحركة… وحدة بتتقطّع ووحدة لأ

المربعين عم يتحركوا بـ CSS animation. الأحمر بـ left، والأخضر بـ transform. اضغط الزر لتشغّل JavaScript تقيل ثانيتين (متل صفحة عم تحمّل)، وراقب مين بيوقف ومين بيكمّل.

🔴 بـ left@keyframes { to { left: … } }
🃏
LayoutPaintComposite
🟢 بـ transform@keyframes { to { transform: … } }
🃏
LayoutPaintComposite

ليش؟ المتصفح بيرسم كل frame بـ 3 مراحل: Layout (وين كل عنصر) ← Paint (الألوان والنصوص) ← Composite (تركيب الطبقات).

left بيغيّر مكان العنصر بالصفحة، فبيعيد الـ 3 مراحل 60 مرة بالثانية، وكلها على الـ main thread. إذا الـ JavaScript مشغول، الحركة بتوقف.

transform وopacity ما بيغيّروا الـ layout، فبيروحوا على الـ Composite بس، واللي بيشتغل على الـ GPU بـ thread لحاله. لهيك بيضلوا ناعمين حتى لو الصفحة مشغولة.

جرّبها كمان من Chrome DevTools: Performance ← سجّل ثانيتين، وشوف الـ Layout البنفسجي مع left.
