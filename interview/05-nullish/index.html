الفرق بين || و ??… جرّب بإيدك

اختار قيمة، وشوف شو بيرجّع كل واحد. || بيسأل «فاضي؟»، و?? بيسأل «مش موجود؟».

1. اختار قيمة لـ value

value || 50
value ?? 50

2. المثال الحقيقي: سكّر الصوت

نزّل الصوت لـ 0. التطبيقين بيقروا نفس الإعداد، بس واحد بـ || والتاني بـ ??.

settings.volume || 50
settings.volume ?? 50

القاعدة: || بيبدّل أي قيمة falsy: 0 و'' وfalse وnull وundefined وNaN. أما ?? بيبدّل بس null وundefined.

استعمل ?? للقيم الافتراضية لما يكون 0 أو '' أو false قيمة صحيحة: صوت، خصم، كمية، أو خيار متسكّر.
