3 مرات +1… والعداد طلع 1؟

هاد React حقيقي. اضغط كل زر مرة وحدة وشوف الرقم. تحت كل زر في طابور بيوريك شو طلب كل سطر من React، وشو صارت القيمة بعده.

ليش؟ بكل render قيمة count ثابتة، متل صورة. فالأسطر التلاتة كلها بتقول لـ React «خلّيها 0 + 1». React بيجمع الطلبات (هاد اسمه batching) وبيعمل render واحد بالآخر، وآخر طلب بيقول 1.

الحل: setCount(c => c + 1). هيك React بيعطي كل طلب آخر قيمة طلعت من الطلب اللي قبله، فبتصير 1 ← 2 ← 3.
