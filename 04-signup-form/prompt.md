# 04 · هاد الفورم… بيخسرك نص المسجلين

**▶ [جرّب الفورمين](https://promptjicode.github.io/promptjicode/04-signup-form/)**: اكتب إيميل غلط بالاتنين، وجرّب من موبايلك لتشوف الاقتراحات التلقائية.

## البرومبت الضعيف

</div>

```
اعملي فورم تسجيل
```

<div dir="rtl">

النتيجة: فورم شكله مرتب، بس لما تغلط بيقلك «يوجد خطأ في البيانات» وما بيقلك وين. وكل شي لازم تكتبه بإيدك.

## البرومبت الصح

</div>

```
اعملي فورم تسجيل بالعربي (اسم، إيميل، كلمة سر).
إذا المستخدم غلط: رسالة واضحة بالعربي تحت الحقل نفسه، وما تطلع قبل ما يخلص كتابة.
خلي الموبايل يعبّي الاسم والإيميل لحاله، وفرجيه شروط كلمة السر وهو عم يكتب.
```

<div dir="rtl">

## شو بتلاقي بالكود

- **`autocomplete`** (`name`، `email`، `new-password`): الموبايل والمتصفح بيقترحوا البيانات ويعبّوها بضغطة.
- **الفحص عند `blur`**: الرسالة بتطلع لما تطلع من الحقل، مو من أول حرف. وبعد ما تطلع، بتختفي أول ما تصلّح.
- **`aria-describedby` و`role="alert"`**: قارئ الشاشة بيقرأ رسالة الخطأ مع الحقل نفسه.
- **شروط كلمة السر** بتصير ✓ وإنت عم تكتب، بدل ما تكتشف الغلط بعد الضغط.

## الفكرة

**قلّه شو لازم يصير لما المستخدم يغلط**، مو بس كيف بدو يبين الفورم.
