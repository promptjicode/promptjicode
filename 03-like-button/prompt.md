# 03 · زر واحد… وفرق كبير بالإحساس

**▶ [جرّب الزرين](https://promptjicode.github.io/promptjicode/03-like-button/)**: اضغط عليهم، وجرّب كمان بالكيبورد (Tab ثم Enter).

## البرومبت الضعيف

</div>

```
اعملي زر لايك
```

<div dir="rtl">

النتيجة: زر بيتلوّن لما تضغطه، وخلص. ما في إحساس، وقارئ الشاشة ما بيعرف إذا مضغوط أو لأ.

## البرومبت الصح

</div>

```
اعملي زر لايك بقلب SVG.
لما ينضغط: القلب بيكبر شوي وبيرجع، بيتلوّن أحمر، وبتطلع منه شرارات صغيرة.
لما ينضغط مرة تانية: بيرجع رمادي بنعومة.
خليه يشتغل بالكيبورد مع aria-pressed، وبدون أنيميشن إذا المستخدم مفعّل تقليل الحركة.
```

<div dir="rtl">

## شو بتلاقي بالكود

- **`<button>` مع `aria-pressed`**: زر حقيقي بيشتغل بالكيبورد لحاله، وقارئ الشاشة بيعرف حالته.
- **أنيميشن بـ `transform: scale`**: ناعم، وما بيعيد ترتيب الصفحة.
- **`prefers-reduced-motion`**: الأنيميشن والشرارات بيوقفوا عند اللي مفعّلين تقليل الحركة.

## الفكرة

**صِف الإحساس اللي بدك ياه، مش بس الشكل.** قلّه شو لازم يصير لما المستخدم يتفاعل، ومين لازم يقدر يستخدمه.
